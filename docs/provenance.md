# Bundle provenance

Behavioral reference: `70ed2c413eee5e3b9dc1324e2c87ff333ee88334`, branch `molmo-motion-final`. This branch and the neighboring research archive are preserved. The original 51 tests passed without skips before migration; the baseline replay regenerated all seven cases from `/tmp`.

`fixtures/<experiment>/observed.npz` contains only causal RGB, timestamps, UV, XYZ, point IDs and available observed calibration. FMB also retains its observed robot reference and frozen motion-policy parameters; its selected kinematic forecast is recalculated using the original `predict` function. Shared Dobb-E history RGB occurs once in `fixtures/shared/`.

Future RGB, reference trajectories, masks and evaluation camera poses remain in `evaluation.npz`. Evaluation is opened only after a forecast has been saved. The `dobbe_hybrid` bundle contains neither a prediction nor evaluation artifacts; the original gate checks still reject `static_median` before processor construction or inference.

All packed arrays use NumPy lossless deflate. Every decoded array was checked against baseline bytes, dtype and shape. Original strides are also restored: NumPy reductions on transposed float32 arrays can otherwise change the last digits even when all elements are equal. No camera, timing, prompt, selected point or arithmetic was changed.

`docs/provenance.json` records original paths and SHA-256, packed paths and SHA-256, transformations, decoded content hashes and compression sizes. Each manifest retains its original source checksums. The six legacy comparison videos remain byte-identical; their presentation purpose is the side-by-side legacy panel.

`tests/golden_manifest.json` contains immutable canonical-input fingerprints, prediction hashes, every method's XYZ/UV fingerprints, every metric and error-array fingerprint, reference/mask fingerprints, original metric records and expected statuses. It was captured before refactoring. The original tests established parity with historical arrays and pure legacy functions; their replacements assert exact complete baseline outputs without importing `legacy/`. Golden data is never regenerated by the verification command.

Processor fingerprints recursively preserve key sets, container/scalar types and values, tensor/array dtype, shape and raw-byte SHA-256. They were extracted from the original `.pt` packets, rather than newly generated processor outputs. Dobb-E had no original full packet; its exact input IDs SHA-256 and historical camera/world equivalence receipt retain that explicit limitation.

Vendored `src/molmo_motion/` is checked against `docs/model_source_snapshot.json` both in the checkout and installed wheel. Its checkpoint remains `allenai/MolmoMotion-4B-H3-F30` revision `3f5e790a511ff2cdf21c8d2a14cb4d8409c94629`. Historical `docs/baseline_verification.json` is provenance only. Final correctness requires a new run of `tools/verify_final.py`, including all fourteen fresh P8 generations; only `docs/final_verification.json` records that proof.
