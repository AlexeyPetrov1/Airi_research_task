# Local data and model files

Keep the selected author example, any later ShareRobot inputs, and the single
MolmoMotion checkpoint here. These files are excluded from Git. The first
checkpoint path is `data/checkpoints/MolmoMotion-4B-H3-F30/`.

The bundled example in `examples/data/davis_bmx_trees/` needs no download.
Do not download the full MolmoMotion-1M or PointMotionBench datasets for setup.
