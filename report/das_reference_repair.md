# DaS: качественное видео с референсом конечного положения

3 октября 2026. Ветка `codex/das-reference-repair-20261003-1642`.

Получен [новый ролик](../runs/berkeley_ur5_molmomotion/cup/das_reference_repair/guided_endpoint_background/generated_seed42.mp4): один узнаваемый голубой стакан движется вместе с захватом; неподвижной копии и следа под старым положением больше нет. Проверены все 49 кадров.

Будущий RGB-кадр 73 разрешён пользователем и используется как конечный референс. Пространственный путь заменён соответствием между начальным и конечным видами; сохранённый MolmoMotion-прогноз задаёт только темп. Это результат синтеза с известным endpoint, не улучшение точности прогнозирования MolmoMotion. Прежний причинный эксперимент сохранён.

| На совпадающих условиях измерения | Старый ролик C | Новый ролик F |
|---|---:|---:|
| PSNR к реальному продолжению, dB | 17.47 | 22.06 |
| Общая область движения: MAE, 0–255 | 43.84 | 19.93 |
| Flow warp MAE в общей области, 0–255 | 7.89 | 3.68 |
| ADE стакана к real на общих 222/240 парах, px | 46.85 | 6.68 |

Сравнение C/F описательное: изменены дополнительные условия и настройки генерации. Для выделения отдельных эффектов проведены matched абляции: E/F добавляет фотографический prior при одном control; E/G убирает только trajectory control при одном prompt и sampler. В E/G ADE к заданному пути составила 8.74 против 59.33 px на общих 224/240 парах. Оценка конечного кадра не является предсказанием неизвестного будущего; отдельно показаны ошибки на промежуточных кадрах 0.2–1.8 с.
