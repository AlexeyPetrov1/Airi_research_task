# Опубликованные результаты исследований

В [индексе отчётов](README.md) собраны исследования Dobb·E, FMB, ShareRobot, PLEX, DAVIS и WorldTrack. Каждый отчёт сохраняет ограничения и статус своего эксперимента; публикация файлов не изменяет научные выводы.

В GitHub сохранены код обработки и оценки, отчёты, метрики, прогнозы, выбранные входные массивы, графики, небольшие видео и квитанции аудита. Основные результаты находятся в `runs/`, скрипты — в `scripts/`. Часть файлов представляет промежуточные диагностические проверки; актуальные выводы приведены в итоговых отчётах и явно помеченных обновлениях.

Правила `.gitattributes` сохраняют точные байты публикуемых файлов FMB, DAVIS и WorldTrack в `runs/` и метаданных второй FMB-сцены, чтобы автоматическое преобразование переносов строк в Git не изменяло их контрольные суммы.

Полные исходные демонстрации, потоки RGB-D и веса моделей хранятся локально либо загружаются из источников, указанных в отчётах. Для второй независимой FMB-сцены опубликованы метаданные, состояние робота, калибровочные файлы и сведения о CAD. Полный исходный файл доступен по закреплённой ссылке Hugging Face в [отчёте экспорта](fmb_second_scene_export.md); RGB и depth можно восстановить [скриптом экспорта](../scripts/export_fmb_second_scene.py). Источники первого FMB-эпизода указаны в [CAD/depth исследовании](fmb_cad_metric_depth_experiment.md).

Для повторного inference необходимы окружение из [SETUP_DIAGNOSTICS](../SETUP_DIAGNOSTICS.md), checkpoint модели и исходные данные конкретного опыта. Аудиты, сравнивающие экспорт с исходной демонстрацией или проверяющие базу COLMAP, также требуют этих локальных данных. Сохранённые метрики, массивы прогноза и визуализации позволяют изучить результаты без повторного запуска модели.

Диагностические скрипты FMB используют клон [исходного кода FMB](https://github.com/rail-berkeley/fmb/tree/d4da6ce044a9806f41e58bf7423b5a3c05289925) в `runs/sharerobot_fmb_episode_5201/fmb_reference_code/`. Для воспроизведения этих проверок следует получить указанный commit; ссылки в отчётах ведут непосредственно на эту ревизию.
